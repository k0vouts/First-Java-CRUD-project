# First-Java-CRUD

A simple CRUD application built with Java, Spring Boot, Vaadin and an H2 database.

## Features
- Create, read, update and delete customers
- Filter customers by last name
- Sample data loaded at startup

## Requirements
- JDK 21
- Maven (the Maven wrapper is included)

## How to run
```
./mvnw spring-boot:run
```
On Windows use `mvnw.cmd spring-boot:run`, or run `DemoApplication` from IntelliJ.
The first start can take a few minutes while Vaadin builds the frontend.
Then open http://localhost:8080
